# Monoprint 0.1.2

This npm patch release fixes `npx monoprint@latest`: the main package now declares
its CLI executable, and each platform package includes the existing Rust CLI
alongside the Node binding. The Node.js API remains available.

- Support all standalone CLI options through npx and global npm installs.
- Verify command discovery, rendering, exit codes and optional-dependency errors
  from freshly installed tarballs on all five supported npm platforms.
- Bind CLI binaries to release receipts and include their dependency notices.

Requires Node.js 22 or newer. Supported platforms are macOS arm64/x64, Linux
glibc arm64/x64, and Windows x64. This publication does not replace desktop
release downloads or update feeds.
