# Monoprint 0.2.4

Expand native syntax highlighting with pierre-highlights-rs 0.2.0, based on
Pierre Highlights 0.4.0.

- Increase native highlighting coverage from 87 to 166 catalog entries,
  including ABAP, Lean, and Apex, in Studio and rendered exports.
- Preserve the remaining 66 catalog entries through the existing Giallo fallback.
- Preserve Python docstring styling when using a separate comment typeface.

Desktop downloads support Apple Silicon macOS and Linux x64/ARM64.
