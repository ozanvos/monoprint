# Monoprint 0.1.0

First release candidate. Public downloads and packages are not available yet.

- Offline PNG, outlined SVG and standalone HTML exports.
- Bundled theme presets, light and dark appearances, and syntax grammars.
- Bundled fonts, separate comment typefaces, coding ligatures and glyph fallback.
- Line and text highlights; theme, solid, lattice, halftone and transparent backgrounds.
- Native macOS studio with a source editor, theme browser, live canvas, copy/export,
  file drops, preview drag-out and Shortcuts.
- Rust API and TypeScript bindings with reusable renderers.

Prepared targets: macOS Apple Silicon app and CLI, Linux x86-64 CLI; Node.js 22+
bindings for macOS arm64/x64, Linux glibc arm64/x64 and Windows x64. Test native builds and signed downloads before distribution. Rust registry publishing
remains disabled until the vendored renderer fixes have published dependencies.
