# Monoprint 0.2.3

Render colored terminal captures and code changes in PNG, SVG and HTML from
Studio, the CLI, and the Rust and Node.js APIs.

- Render ANSI terminal colors and text styles, including progress-line redraws
  and man-page overstrikes. Select the `ansi` language or open a `.ans` file.
- Compare two files, render a single-file unified patch, or mark snippet lines
  as added and removed, with syntax colors and configurable context.
- Polish Studio controls and move the language label to the footer.
- Keep the macOS DMG artwork fully visible when Finder's path and status bars
  are shown.
- Update website download instructions, platform copy and link previews.

See the [terminal output and code changes guide](https://github.com/ozanvos/monoprint/blob/v0.2.3/docs/terminal-and-changes.md)
for examples and supported input.

Desktop downloads support Apple Silicon macOS and Linux x64/ARM64.
