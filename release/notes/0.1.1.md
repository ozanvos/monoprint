# Monoprint 0.1.1

- Add a native Linux ARM64 AppImage alongside the existing Linux x64 download.
- Build and qualify both Linux architectures in CI, including packaged startup,
  saved-draft restart, and Velopack update discovery, download and replacement.
- Give each Linux architecture its own update channel and website download.

Linux AppImages require Ubuntu 24.04 or newer, or a compatible distribution, and
a working Vulkan driver. macOS remains available as a signed and notarized Apple
Silicon app. Windows desktop downloads remain deferred.
