# Monoprint 0.1.3

- Publish npm packages through GitHub Actions trusted publishing with provenance.
- Add an npm-only release mode, live OIDC verification, and public package integrity checks.
- Keep the CLI and Node.js rendering behavior introduced in 0.1.2.

This release validates automated npm distribution for macOS arm64/x64, Linux glibc arm64/x64, and Windows x64.
