# Monoprint 0.1.4

This release brings the desktop app, bundled CLI, and npm packages to the same
version from the same source revision.

- Add **Monoprint → About Monoprint** on macOS, showing the app icon, version,
  build number, and copyright in the standard macOS About panel.
- Include the latest Linux window controls, display sizing, installation, and
  AppImage update improvements.
- Include the `npx monoprint` CLI fixes and npm trusted publishing with provenance
  introduced in the npm-only 0.1.2 and 0.1.3 releases.

Desktop downloads support Apple Silicon macOS and Linux x64/ARM64. npm packages
support macOS arm64/x64, Linux glibc arm64/x64, and Windows x64. Windows desktop
downloads remain deferred.
