Monoprint support

For help, bug reports or feedback, email contact@7ea.st.

Create your first image

  1. Paste code into the left editor or open a UTF-8 source file.
  2. Choose a language and theme.
  3. Set the width, padding, backdrop and optional filename.
  4. Choose PNG, SVG or HTML, then click Export.

Light and dark appearances

The theme's appearance switch controls your code image. The sun/moon button in the top bar changes the app interface separately.

Transparent exports

Choose None in the Backdrop settings. PNG and SVG preserve transparency; the preview uses a checkerboard to show transparent areas.

Highlighting and fonts

Select the correct language in the top bar for syntax highlighting. Select code to access line and text highlights. In Typeface settings, choose a bundled font or load a TTF/OTF font file.

Reporting a problem

Include your macOS version, Monoprint version, the export format and the steps that reproduce the issue. A small non-sensitive code sample or screenshot helps. Remove private source code and personal details before sending attachments.
